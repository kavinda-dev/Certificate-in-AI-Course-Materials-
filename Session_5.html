Session 5 • Topic 1

Claude AI vs. Gemini AI Matrix

Softwares: Gemini AI & Claude AI

Claude AI (Anthropic)

Deep Reasoning & Structural Nuance

Key Strengths: Complex document reasoning, extended context windows, executive writing style, XML structural tagging.
Best Used For: Drafting policy documents, synthesizing messy transcripts, coding logic, and formal whitepapers.

Gemini AI (Google)

Live Web & Google Workspace Integration

Key Strengths: Real-time Google Search indexing, seamless Gmail/Docs/Drive integrations, multimodal analysis.
Best Used For: Live market research, instant email responses inside Gmail, spreadsheet formula generation, and planning.
Recommended Model Strategy by Task:

-> Gemini AI

-> Claude AI

Session 5 • Topic 2

The C-R-E-A-T-E Prompting Framework

C Context

Describe the exact scenario, background details, and current operational environment.

R Role

Specify the expert persona and experience level (e.g., Senior Operations Director).

E Explicit Task

State precisely what actions the model must execute step-by-step.

A Anti-Goals

Set explicit negative boundaries (e.g., "Do NOT use buzzwords or alter numbers").

T Tone & Format

Define desired length, tone (concise, formal), and visual layout (Markdown table).

E Examples

Provide few-shot sample output formats to guide model response structure.

Session 5 • Topic 3

Executive Communication Engineering

Raw / Messy Input Draft
"Hey team, so server went down yesterday at 3pm because of memory leak. Project delivery is delayed by 3 days. Need everyone to work overtime tomorrow to fix the client database."
AI-Transformed Executive Output
Subject: Operational Update: System Remediation & Adjusted Project Timeline

Dear Stakeholders,
Following yesterday's brief memory optimization event, our team has implemented corrective safeguards. To ensure system stability, the target deployment is revised by 72 hours.

Tone Transformation Mechanics:

1. Passive to Directive: Convert reactive statements into clear accountability steps.
2. De-escalation: Reframe operational delays around quality assurance.
3. Action Assignment: Ensure every email contains a clear Owner and SLA deadline.
